# Flask-Server
A flask server to return a single joke or a list of jokes

## get_joke()
Returns a single joke
Parameters - none

## get_jokes()
Return a list of jokes
Parameters - none

## Commands to run code
1. create a virtual environment and install flask inside of it
```
python -m venv venv # creating the venv
cd venv # go inside venv folder
venv\Scripts\activate # activate the venv folder
pip install flask # installing flask inside venv
```
2. Install pyjokes, import pyjokes inside app.py
```
pip install pyjokes
python app.py #run the server
```
